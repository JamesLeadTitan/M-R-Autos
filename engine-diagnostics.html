How It Works

What To Expect

A fault code is a starting point, not a diagnosis.

When a warning light comes on, the vehicle stores a code describing what it noticed. That code might say the oxygen sensor readings are out of range, but the cause could be the sensor itself, a wiring fault, an air leak upstream or a fuelling problem elsewhere. Replacing whatever the code names is how people end up paying twice, so we do not work that way.

We start with what you have noticed, because a symptom that only appears cold, or only on a long run, narrows things down faster than any scanner. Then we pull the stored codes and watch live data while the engine is running, which shows what the sensors are actually reporting rather than what they reported once last Tuesday. From there it is physical testing to prove the fault.

You get told what has failed, why it failed and what putting it right involves, in language that makes sense. Intermittent faults are honest work: if something only misbehaves once a fortnight, we will say so rather than pretending a single visit can guarantee it is gone. Sometimes the useful answer is what we have ruled out.
